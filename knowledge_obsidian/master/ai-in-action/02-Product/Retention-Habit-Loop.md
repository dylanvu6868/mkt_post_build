# Retention, Engagement & Habit Loop
**Day 19 · Track 1** · Build products users come back to

## North Star Metric
Single metric reflecting core value delivered to users.
*Examples*: Airbnb=booked nights, Spotify=time listened

## Natural vs Nurture
| Natural (intrinsic need) | Nurture (product actions) |
|--------------------------|----------------------------|
| Frequency based on use case | Notifications, emails |
| Daily → DAU, Weekly → WAU | Reminders, onboarding |
| *Don't fight nature* | *Nurture amplifies nature* |

## Hook Model
1. **Trigger** (external: notification; internal: feeling)
2. **Action** (simplest behavior → reward)
3. **Variable Reward** (tribe/hunt/self rewards)
4. **Investment** (user puts in → more likely to return)

## Metric Selection (by natural frequency)
| Frequency | Metric |
|-----------|--------|
| Daily | DAU, D1/D7/D30 retention, DAU/MAU |
| Weekly | WAU, weekly cohort retention |
| Monthly | MAU |
| Quarterly/Yearly | Custom window matching next occurrence |

## Core Action ≠ Any Click
Core action = behavior closest to value delivered.
*Measurement ladder*: Visitor → Activation → Core Action → Retention → Revenue

## Anti-Patterns
- Copying Duolingo streaks without understanding learning motivation
- "Pivot lite" when retention is fundamentally broken (need core value fix, not UI polish)
- Forcing daily retention on monthly use case
