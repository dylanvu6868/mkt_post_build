# AI Prototyping & MVP
**Day 17 · Track 1** · Test hypotheses before full build

## Wizard of Oz MVP
Fake the AI at first — validate demand before building tech.
- DoorDash: static website + PDF menus + manual delivery
- AI note-taking startup: 2 founders taking notes by hand, charging $100/mo → $1B valuation

## Prototype Fidelity Ladder
| Level | Tool | When |
|-------|------|------|
| Sketch + Wireframe | Paper/FigJam | Workflow unclear |
| Mockup | Figma/Slide | Need stakeholder buy-in |
| Interactive Prototype | Cursor/Claude | Need user test |
| MVP | Cursor/Code | Build quickly after validation |

## Leap of Faith Assumptions
1. **Value risk**: Will users choose this?
2. **Usability risk**: Can they figure it out?
3. **Feasibility risk**: Can we build it?
4. **Business viability risk**: Does it work for the business?

## Lab Workflow
1. Pick 1 hypothesis from your project
2. Think 3 cheapest ways to test it
3. Prototype all 3 fast
4. Present & compare
