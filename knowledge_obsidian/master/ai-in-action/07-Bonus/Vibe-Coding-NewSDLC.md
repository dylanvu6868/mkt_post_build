# Vibe Coding & New SDLC
**Bonus** · Building with AI, not just using AI

## Mindset Shift
- From "I write code" → "I direct AI to write code"
- Intent-driven: state goal + constraints + success criteria
- Context-first: relevant files, examples, constraints
- Human review: AI writes fast; human owns quality

## AI-Native PRD
Traditional PRD + AI-specific additions:
- Eval rubric (pass/fail criteria, not just "user wants X")
- Golden outputs (expected answers for known cases)
- Failure modes (what happens when AI is wrong/unsure)
- Data strategy (where does AI get knowledge?)
- Safety gates (what blocks deploy?)

## Recommended Stack
Cursor / VS Code + Copilot + Claude Code.
Prompt = goal + context + pattern + test.
